# AuctionApp — Interactive Demo

This folder hosts a static, clickable mockup of AuctionApp on GitHub Pages. AuctionApp itself is an Android app (Java + Firebase Realtime Database) and cannot run in a browser, so this demo walks through the real screenshots screen by screen for both the bidder and admin flows. The source for the actual Android app lives in the parent repository at [github.com/deqa-jaja/AuctionApp](https://github.com/deqa-jaja/AuctionApp).
